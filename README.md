## Дүгнэлт (Debrief)

Энэхүү лабораторийн ажлаар Session-Based Test Management (SBTM) болон Exploratory тестийн аргачлалыг "Уншлагын жагсаалт" веб апп дээр амжилттай хэрэгжүүллээ. Туршилтын явцад Supermodel, Couch Potato болон Saboteur аялалуудыг хослуулан ашигласнаас Saboteur болон Supermodel аялалууд хамгийн үр дүнтэй байж согогуудыг илрүүлсэн. Тодруулбал, UI түвшинд оны шалгалт дутуу байсан болон ижил ном давхардан нэмэгдэж байсан согогуудыг олов. Мөн curl ашиглан API түвшинд довтолгоо хийхэд дутуу JSON өгөгдөлд 500 алдаа буцааж буй чухал согогийг илрүүлсэн. Charter-аас гадуур хайлтын системд том жижиг үсэг ялгаж буй сэжигтэй зан төлөв ажиглагдсан бөгөөд үүнийг дараагийн сессийн charter-т оруулахаар төлөвлөлөө. Эдгээр олдсон согогуудаас оны validation болон давхардлын шалгалтууд нь Лаб 1-ийн Playwright автомат тестээр хялбар баригдах боломжтой байсан. Харин API-ийн буруу статус код болон UI-ийн текстийн утга зүйн согогууд нь зөвхөн хүний судлан шинжлэх туршилтын нүдээр олдох боломжтой байв. Энхийн ба туршилтын сессээр дамжуулан системд урьдчилан таамаглаагүй алдаануудыг богино хугацаанд баримтжуулан тайлагнаж сурсан нь чанарын баталгаажуулалтад маш том туршлага боллоо.
